# 주식 모의투자 앱 기획서 (가제: STOCK)

> 한국·미국 실제 시세로, 실전과 같은 규칙으로 매매 연습하는 앱.
> 토스증권처럼 깔끔하게, 웹으로 시작해서 APK로 확장.

---

## 1. 확정 사항

| 항목 | 결정 |
|---|---|
| 플랫폼 | 웹앱(PWA) 먼저 → Capacitor로 안드로이드 APK |
| 시세 | 한국투자증권 Open API (KIS Developers), 실시간 |
| 시장 | 한국(코스피·코스닥), 미국(나스닥·NYSE·AMEX) |
| 사용자 | 혼자 사용. 단, DB는 처음부터 `user_id` 넣어서 다중 사용자 확장 가능하게 |
| 주문 리얼도 | 실전형: 지정가/시장가, 수수료·세금, 장 시간, 환전, 호가단위, 가격제한폭 |
| 시드머니 | 원화 1,000만원. 미국주식은 실제 환율로 달러 환전 후 매수. 리셋 가능 |
| 디자인 | 토스증권 스타일 (모바일 우선, 큰 숫자, 심플, 라이트/다크) |
| 알림 | 폰 푸시 (웹 푸시 → APK에서는 FCM 네이티브 푸시) |
| 배포 | 클라우드 무료 배포 |
| 기술 스택 | 전부 TypeScript (React 웹 + Node 서버) — 아래 5장 |

**하지 않는 것**: 실제 계좌 주문(시세만 읽음), 신용·공매도·옵션·선물.

## 2. 기능 명세

### MVP (1단계)

**① 종목 검색 + 차트**
- 한글/영문/종목코드/초성 검색 (`ㅅㅅㅈㅈ` → 삼성전자)
- 캔들차트: 분봉(1·5·15·60분), 일봉, 주봉, 월봉 + 거래량
- 기본 지표: 이동평균선(5·20·60·120), 볼린저밴드, RSI
- 현재가·등락률 실시간 갱신, 10단계 호가창(국내), 체결 내역

**② 매수/매도 + 포트폴리오**
- 주문: 시장가 / 지정가, 미체결 조회·정정·취소
- 주문 전 확인창: 예상 체결금액, 수수료, 세금, 주문 후 잔고
- 내 계좌: 총자산, 원화/달러 예수금, 보유종목별 평균단가·수익률·평가손익
- 원/달러 합산 수익률 (환차손익 별도 표시)
- 환전: 원 ↔ 달러, 실제 환율 + 환전 스프레드
- 계좌 리셋 (리셋 전 기록은 '시즌'으로 보관)

**③ 관심종목 + 가격 알림**
- 관심종목 그룹(예: 반도체, 미국 빅테크), 순서 변경
- 알림 조건: 목표가 도달, 등락률 ±N%, 지정가 체결됨
- 서버가 24시간 감시 → 폰 푸시

**④ 매매일지 + 통계**
- 매매할 때 '왜 샀는지/팔았는지' 메모 + 태그(뇌동매매, 손절, 분할매수 등)
- 통계: 승률, 평균 수익/손실, 손익비, 최대 낙폭(MDD), 보유기간
- 내 자산 추이 그래프 vs 코스피/S&P500 비교
- 월별 수익 캘린더 (토스 스타일 초록/빨강 달력)

### 2단계 (차별화 기능)

**⑤ AI 투자 코치** (Claude API)
- 주간 매매 복기 리포트: "이번 주 손실 70%가 장 시작 10분 내 추격매수에서 나옴"
- 매매일지 피드백: 적은 이유와 실제 행동이 맞는지 짚어줌
- 종목 한눈에 요약: 최근 주가 흐름, 재무 요약
- 주의: "투자 조언 아님" 고지, 매수/매도 추천은 하지 않음

**⑥ 챌린지 / 업적**
- 챌린지: "한 달 +5%", "손절 원칙 10번 지키기", "MDD -10% 이내로 한 달"
- 업적 배지: 첫 매수, 첫 익절, 10연승, 미국주식 데뷔, 리플레이에서 코로나장 생존 등
- 시즌제: 계좌 리셋할 때마다 시즌 기록 남김

**⑦ 타임머신 리플레이**
- 과거 날짜 선택 (예: 2020.03 코로나 폭락, 2022 금리인상장) → 그 시점부터 차트가 다시 재생
- 재생 속도 조절 (1일 = 1초 등), 미래 데이터 안 보임
- 본 계좌와 분리된 리플레이 전용 계좌, 결과는 챌린지/업적과 연동
- 일봉 기준으로 시작 (KIS 과거 분봉은 제한적이라 추후 검토)

## 3. 매매 규칙 (실전형)

모든 숫자는 **설정값**으로 관리 → 세법·수수료 바뀌면 숫자만 수정.

| 항목 | 한국 | 미국 |
|---|---|---|
| 정규장 (한국시간) | 09:00~15:30 | 23:30~06:00 (서머타임 22:30~05:00) |
| 매매 수수료 | 0.015% | 0.25% |
| 매도 세금 | 증권거래세 0.20% (2026 기준) | SEC 수수료 등 소액 (설정값) |
| 호가단위 | 가격대별 1~1,000원 | $1 이상 $0.01, 미만 $0.0001 |
| 가격제한폭 | 전일 종가 ±30% | 없음 |
| 휴장일 | KRX 휴장일 캘린더 | NYSE 휴장일 캘린더 |

**체결 로직**
- 시장가: 매수는 매도1호가, 매도는 매수1호가로 즉시 전량 체결
- 지정가: 실시간 체결가가 지정가에 닿으면 체결 (매수: 현재가 ≤ 지정가)
- 장 시간 외 주문: '예약주문'으로 저장 → 다음 장 시작 시 처리
- 미국주식은 달러 예수금 부족 시 주문 거부 (자동 환전 없음 — 직접 환전)
- 환전: 기준환율 ± 스프레드 1% (우대율 설정 가능)
- 양도세(미국 연 250만원 초과분 22%)는 2단계에서 '예상 세금'으로 표시

**MVP에서 단순화하는 것** (나중에 추가 가능)
- 부분 체결 없음 (전량 체결)
- 시간외 거래, 넥스트레이드(NXT), 미국 프리/애프터마켓 미지원
- 배당·액면분할 반영은 2단계

## 4. 화면 구성

하단 탭 5개 (토스 스타일):

1. **홈** — 총자산, 오늘 수익, 보유종목 카드, 시장 지수(코스피·코스닥·나스닥·S&P500·환율)
2. **관심** — 관심종목 그룹 리스트, 실시간 시세
3. **검색/발견** — 검색, 거래대금·급등락 순위
4. **일지** — 매매일지, 통계, 수익 캘린더 (2단계: AI 코치 리포트)
5. **더보기** — 환전, 알림 관리, 챌린지/업적, 리플레이, 설정, 계좌 리셋

종목 상세 화면: 차트 / 호가 / 내 보유 정보 / 구매·판매 버튼 → 주문 바텀시트

## 5. 기술 구조

```
 [폰/브라우저]  React 웹앱 (PWA, Capacitor로 APK)
       │  REST + WebSocket
 [서버]  Node.js (Fastify)
       ├─ 시세 중계: KIS 실시간 WebSocket 1개 연결 → 앱에 재전달
       ├─ 체결 엔진: 지정가/예약주문 감시 후 체결
       ├─ 알림 감시 → 푸시 발송
       └─ DB: SQLite (확장 시 Postgres)
       │
 [한국투자증권 Open API]  시세만 사용 (주문 API는 호출 안 함)
```

| 영역 | 선택 | 이유 |
|---|---|---|
| 프론트 | React + TypeScript + Vite + Tailwind | 표준, 빠름 |
| 차트 | TradingView Lightweight Charts | 무료, 증권앱 수준 캔들차트 |
| 서버 | Node.js + Fastify + TypeScript | 프론트와 언어 통일 |
| DB | SQLite + Drizzle ORM | 설치 없이 시작, 나중에 Postgres로 이전 쉬움 |
| APK | Capacitor | 웹 코드 그대로 안드로이드 앱으로 |
| 푸시 | Web Push(VAPID) → APK에서는 FCM | |
| 테스트 | Vitest | 매매 규칙 엔진 위주로 촘촘히 |

**폴더 구조 (모노레포)**
```
apps/web        웹앱 (+ Capacitor 설정)
apps/server     API 서버, 시세 중계, 체결 엔진, 알림
packages/core   매매 규칙 (수수료·세금·호가단위·장시간·체결) — 순수 함수
packages/shared 공용 타입
docs/           기획·설계 문서
```

**시세 데이터 설계**
- `MarketDataProvider` 인터페이스 → `KisProvider`(실제) / `MockProvider`(개발·테스트용 가짜 시세)
- 종목 목록: KIS 종목 마스터 파일을 매일 새벽 내려받아 DB에 저장 → 검색에 사용
- KIS 제약 대응
  - 접근토큰: 하루 유효, 재발급 횟수 제한 → 서버에서 캐싱
  - 초당 호출 제한 → 서버에서 요청 큐잉 + 짧은 캐시
  - 실시간 구독 종목 수 제한(약 40개) → 보유·관심·지금 보는 종목 우선 구독, 나머지는 주기적 조회

**보안**
- KIS 앱키·시크릿은 서버 환경변수에만 (앱/깃에 절대 안 들어감)
- 서버는 KIS **시세 API만 허용 목록**으로 호출 → 실제 주문 불가능하게 차단
- 클라우드에 올리면 누구나 주소로 접속 가능 → 혼자 써도 **로그인(비밀번호) 필수**

**배포 (무료)**
- 서버는 24시간 켜져 있어야 함 (지정가 체결·알림 감시 때문)
- 추천: Oracle Cloud Always Free VM 1대에 서버+웹 같이 올림
- 대안: Render 무료 플랜 (15분 미사용 시 잠들어서 알림이 늦어짐 → 비추천)

## 7. 로드맵

| 단계 | 내용 | 결과물 |
|---|---|---|
| **M0 뼈대** | 모노레포, 가짜 시세(Mock), 기본 화면 틀, 매매 규칙 엔진 + 테스트 | 가짜 시세로 돌아가는 화면 |
| **M1 시세** | KIS 연동, 종목 검색, 차트, 호가, 지수·환율 | 진짜 시세 보이는 앱 |
| **M2 매매** | 주문/체결 엔진, 수수료·세금, 환전, 포트폴리오, 리셋 | 모의투자 가능 |
| **M3 관리** | 관심종목, 알림+웹 푸시, 매매일지, 통계, 수익 캘린더 | **MVP 완성** |
| **M4 배포** | 로그인, 클라우드 배포, Capacitor APK, FCM 푸시 | 폰에 설치 |
| **M5 차별화** | AI 코치, 챌린지/업적, 타임머신 리플레이 | 2단계 완성 |

## 9. 아직 안 정한 것

- 앱 이름
- KIS 키를 실전 계좌 키로 쓸지 모의투자 키로 쓸지 (M1에서 호출 한도·미국 시세 지원 여부 테스트 후 결정)
- 시간외/NXT/미국 프리·애프터마켓 지원 여부 (MVP 이후)
- 리플레이에 분봉까지 넣을지 (데이터 소스 확인 후)
