# 주식 모의투자 앱 기획서 (가제: STOCK)

> 한국·미국 실제 시세로, 실전과 같은 규칙으로 매매 연습하는 앱.
> 토스증권처럼 깔끔하게, 웹으로 시작해서 APK로 확장.
> **기본 기능은 키·가입·비용 없이 동작**하는 게 원칙.

---

## 1. 확정 사항

| 항목 | 결정 |
|---|---|
| 플랫폼 | 웹앱(PWA) 먼저 → Capacitor로 안드로이드 APK |
| 시세 | 기본: 야후 파이낸스 (키 없음, 무료). 선택: 한국투자증권 API 키 넣으면 실시간으로 업그레이드 |
| 시장 | 한국(코스피·코스닥), 미국(나스닥·NYSE·AMEX) |
| 사용자 | 혼자 사용. 단, DB는 처음부터 `user_id` 넣어서 다중 사용자 확장 가능하게 |
| 주문 리얼도 | 실전형: 지정가/시장가, 수수료·세금, 장 시간, 호가단위, 가격제한폭 |
| 시드머니 | 원화 1,000만원. 미국주식은 실제 환율로 달러 환전 후 매수. 리셋 가능 |
| 디자인 | 토스증권 스타일 (모바일 우선, 큰 숫자, 심플, 라이트/다크) |
| 알림 | 폰 푸시 (웹 푸시 → APK에서는 FCM 네이티브 푸시) |
| AI 코치 | ① 규칙 기반 코치(무료) ② "AI에게 물어보기" 복사 버튼(무료) ③ AI API 연동(선택, 유료) |
| 배포 | 클라우드 무료 배포 |
| 기술 스택 | 전부 TypeScript (React 웹 + Node 서버) — 아래 5장 |

**하지 않는 것**: 실제 계좌 주문, 신용·공매도·옵션·선물.

## 2. 기능 명세

### MVP (1단계)

**① 종목 검색 + 차트**
- 한국주식: 한글/종목코드/초성 검색 (`ㅅㅅㅈㅈ` → 삼성전자)
- 미국주식: 티커/영문명 검색 (자주 찾는 종목은 한글명 별칭 추가 — 예: "애플" → AAPL)
- 캔들차트: 분봉(1·5·15·60분), 일봉, 주봉, 월봉 + 거래량
- 기본 지표: 이동평균선(5·20·60·120), 볼린저밴드, RSI
- 현재가·등락률 자동 갱신 (몇 초 간격)
- 호가창: 한투 API 연결 시에만 표시 (야후는 호가 데이터 없음)

**② 매수/매도 + 포트폴리오**
- 주문: 시장가 / 지정가, 미체결 조회·정정·취소
- 주문 전 확인창: 예상 체결금액, 수수료, 세금, 주문 후 잔고
- 내 계좌: 총자산, 원화/달러 예수금, 보유종목별 평균단가·수익률·평가손익
- 원/달러 합산 수익률 (환차손익 별도 표시)
- 환전: 원 ↔ 달러, 실제 환율 + 환전 스프레드
- 계좌 리셋 (리셋 전 기록은 '시즌'으로 보관)

**③ 관심종목 + 가격 알림**
- 관심종목 그룹(예: 반도체, 미국 빅테크), 순서 변경
- 알림 조건: 목표가 도달, 등락률 ±N%, 지정가 체결됨
- 서버가 24시간 감시 → 폰 푸시

**④ 매매일지 + 통계**
- 매매할 때 '왜 샀는지/팔았는지' 메모 + 태그(뇌동매매, 손절, 분할매수 등)
- 통계: 승률, 평균 수익/손실, 손익비, 최대 낙폭(MDD), 보유기간
- 내 자산 추이 그래프 vs 코스피/S&P500 비교
- 월별 수익 캘린더 (토스 스타일 초록/빨강 달력)

### 2단계 (차별화 기능)

**⑤ AI 투자 코치 — 3가지 방식**

| 방식 | 비용 | 하는 일 |
|---|---|---|
| ① 규칙 기반 코치 | 무료 | 매매 기록을 규칙으로 분석해서 습관을 짚어줌 (기본 탑재) |
| ② AI에게 물어보기 | 무료 | 매매 기록+일지를 정리된 질문으로 만들어 복사 → Claude·ChatGPT 앱에 붙여넣기 |
| ③ AI API 연동 | 유료 (선택) | 설정에서 API 키 넣으면 앱 안에서 바로 AI 리포트·대화 |

① 규칙 기반 코치 — 분석 항목 예시
- 추격매수: "당일 +5% 이상 오른 뒤 산 거래 12건, 그중 9건 손실"
- 손절 미준수: "-5% 손절 정해놓고 -12%까지 버틴 거래 3건"
- 물타기: "손실 중 추가매수한 종목 평균 수익률 -8%"
- 과매매: "하루 평균 15회 매매, 수수료로 총 4.2만원 지출"
- 시간대: "장 시작 10분 내 매매 승률 30%, 나머지 시간 55%"
- 집중도: "자산의 60%가 한 종목에 몰려 있음"
- 주간 리포트로 묶어서 보여주고, 챌린지/업적과 연동

② AI에게 물어보기
- 버튼 하나로 기간·거래내역·일지 메모·통계를 질문 형식으로 정리해 클립보드에 복사
- 질문 템플릿 선택: "이번 주 매매 복기", "이 종목 왜 손해 봤을까", "내 매매 습관 분석"

③ AI API 연동 (선택)
- 키 없으면 메뉴 자체가 숨겨짐 → 기본 사용에 영향 없음
- 공급자 교체 가능하게 설계 (Claude, Gemini 등)

공통: "투자 조언 아님" 고지, 특정 종목 매수/매도 추천은 하지 않음

**⑥ 챌린지 / 업적**
- 챌린지: "한 달 +5%", "손절 원칙 10번 지키기", "MDD -10% 이내로 한 달"
- 업적 배지: 첫 매수, 첫 익절, 10연승, 미국주식 데뷔, 리플레이에서 코로나장 생존 등
- 시즌제: 계좌 리셋할 때마다 시즌 기록 남김

**⑦ 타임머신 리플레이**
- 과거 날짜 선택 (예: 2020.03 코로나 폭락, 2022 금리인상장) → 그 시점부터 차트가 다시 재생
- 재생 속도 조절 (1일 = 1초 등), 미래 데이터 안 보임
- 본 계좌와 분리된 리플레이 전용 계좌, 결과는 챌린지/업적과 연동
- 일봉 기준 (야후는 수십 년치 일봉 제공. 과거 분봉은 최근 기간만 있어서 제외)

## 3. 매매 규칙 (실전형)

모든 숫자는 **설정값**으로 관리 → 세법·수수료 바뀌면 숫자만 수정.

| 항목 | 한국 | 미국 |
|---|---|---|
| 정규장 (한국시간) | 09:00~15:30 | 23:30~06:00 (서머타임 22:30~05:00) |
| 매매 수수료 | 0.015% | 0.25% |
| 매도 세금 | 증권거래세 0.20% (2026 기준) | SEC 수수료 등 소액 (설정값) |
| 호가단위 | 가격대별 1~1,000원 | $1 이상 $0.01, 미만 $0.0001 |
| 가격제한폭 | 전일 종가 ±30% | 없음 |
| 휴장일 | KRX 휴장일 캘린더 | NYSE 휴장일 캘린더 |

**체결 로직**
- 시장가: 현재가로 즉시 전량 체결 + 슬리피지 옵션(기본 0.05%, 매수는 비싸게·매도는 싸게)
  - 한투 API 연결 시: 매수는 매도1호가, 매도는 매수1호가로 체결
- 지정가: 갱신된 현재가가 지정가에 닿으면 체결 (매수: 현재가 ≤ 지정가)
- 장 시간 외 주문: '예약주문'으로 저장 → 다음 장 시작 시 처리
- 미국주식은 달러 예수금 부족 시 주문 거부 (자동 환전 없음 — 직접 환전)
- 환전: 기준환율 ± 스프레드 1% (우대율 설정 가능)
- 양도세(미국 연 250만원 초과분 22%)는 2단계에서 '예상 세금'으로 표시

**시세 지연 관련**
- 야후 한국주식 시세는 약 20분 지연 → 앱 안에서 보는 가격과 체결 가격이 같으므로 연습에는 문제없음
- 화면에 "20분 지연 시세" 표시, 장 시간 판단은 실제 시각 기준

**MVP에서 단순화하는 것** (나중에 추가 가능)
- 부분 체결 없음 (전량 체결)
- 시간외 거래, 넥스트레이드(NXT), 미국 프리/애프터마켓 미지원
- 배당·액면분할 반영은 2단계

## 4. 화면 구성

하단 탭 5개 (토스 스타일):

1. **홈** — 총자산, 오늘 수익, 보유종목 카드, 시장 지수(코스피·코스닥·나스닥·S&P500·환율)
2. **관심** — 관심종목 그룹 리스트, 시세
3. **검색/발견** — 검색, 거래대금·급등락 순위
4. **일지** — 매매일지, 통계, 수익 캘린더, 코치 리포트, AI에게 물어보기
5. **더보기** — 환전, 알림 관리, 챌린지/업적, 리플레이, 설정(시세 소스·API 키), 계좌 리셋

종목 상세 화면: 차트 / (호가) / 내 보유 정보 / 구매·판매 버튼 → 주문 바텀시트

## 5. 기술 구조

```
 [폰/브라우저]  React 웹앱 (PWA, Capacitor로 APK)
       │  REST + WebSocket
 [서버]  Node.js (Fastify)
       ├─ 시세 수집: 야후에서 주기적으로 가져와 캐시 → 앱에 전달
       ├─ 체결 엔진: 지정가/예약주문 감시 후 체결
       ├─ 알림 감시 → 푸시 발송
       ├─ 코치 엔진: 규칙 분석, 프롬프트 생성, (선택) AI API 호출
       └─ DB: SQLite (확장 시 Postgres)
       │
 [시세 소스]  야후 파이낸스 (기본)  /  한국투자증권 API (선택)
```

| 영역 | 선택 | 이유 |
|---|---|---|
| 프론트 | React + TypeScript + Vite + Tailwind | 표준, 빠름 |
| 차트 | TradingView Lightweight Charts | 무료, 증권앱 수준 캔들차트 |
| 서버 | Node.js + Fastify + TypeScript | 프론트와 언어 통일 |
| DB | SQLite + Drizzle ORM | 설치 없이 시작, 나중에 Postgres로 이전 쉬움 |
| APK | Capacitor | 웹 코드 그대로 안드로이드 앱으로 |
| 푸시 | Web Push(VAPID) → APK에서는 FCM | |
| 테스트 | Vitest | 매매 규칙 엔진·코치 규칙 위주로 촘촘히 |

**폴더 구조 (모노레포)**
```
apps/web        웹앱 (+ Capacitor 설정)
apps/server     API 서버, 시세 수집, 체결 엔진, 알림, 코치
packages/core   매매 규칙 (수수료·세금·호가단위·장시간·체결) + 코치 규칙 — 순수 함수
packages/shared 공용 타입
docs/           기획·설계 문서
```

**시세 데이터 설계**
- `MarketDataProvider` 인터페이스 하나로 통일 → 구현체만 바꿔 끼움
  - `YahooProvider` — 기본
  - `KisProvider` — 한투 키 있을 때 (실시간·호가)
  - `MockProvider` — 개발·테스트용 가짜 시세
- 야후 사용 방식
  - 비공식이라 차단·형식 변경 가능 → 서버에서만 호출, 응답 캐시, 실패 시 재시도·마지막 값 유지
  - 갱신 주기: 지금 보는 종목 3~5초, 보유·관심 종목 15~30초, 나머지 요청 시에만
  - 지수·환율도 야후에서 (코스피 `^KS11`, 코스닥 `^KQ11`, 나스닥 `^IXIC`, S&P500 `^GSPC`, 원달러 `KRW=X`)
- 종목 목록: 공개된 종목 목록 파일(KRX·나스닥 등)을 주기적으로 받아 DB에 저장 → 검색에 사용

**보안**
- API 키(한투·AI)는 서버 환경변수/설정에만 저장, 앱·깃에 절대 안 들어감
- 한투 연결 시 **시세 API만 허용 목록**으로 호출 → 실제 주문 불가능하게 차단
- 클라우드에 올리면 누구나 주소로 접속 가능 → 혼자 써도 **로그인(비밀번호) 필수**

**배포 (무료)**
- 서버는 24시간 켜져 있어야 함 (지정가 체결·알림 감시 때문)
- 추천: Oracle Cloud Always Free VM 1대에 서버+웹 같이 올림
- 대안: Render 무료 플랜 (15분 미사용 시 잠들어서 알림이 늦어짐 → 비추천)
- 주의: 야후 데이터는 개인 사용 전제 → 다른 사람에게 공개 배포할 땐 공식 데이터 소스로 전환 필요
